## 启动与失败记录约定

包内提供以下入口。普通离线入口中，居民自主决定来自规则；对话里的“生成”使用固定客户端，不发送 HTTP。`Start-1920.cmd` 与 `Start.cmd` 共用普通档，其他模式各自隔离。

| 包内入口 | 状态与数据目录 `<data>` |
| --- | --- |
| `Start.cmd` / `Start-1920.cmd` | `baseline`，`<package>/user-data/baseline/`；请求窗口为 1280×720 / 1920×1080 |
| `Start-counterfactual.cmd` | 只改变居民初始资源的对照；`<package>/user-data/counterfactual/` |
| `Run-delayed.cmd` / `Run-invalid.cmd` / `Run-timeout.cmd` / `Run-budget.cmd` | 各用 `<package>/user-data/dialogue-<fixture>/`；依次为约 2 秒延迟、结构错误、60 秒逻辑等待、预算拒绝的离线样例 |
| `Run-farming-capacity.cmd` | `farming-capacity-fixture`，`<package>/user-data/farming-capacity/`；五格种植容量样例 |
| `Run-production-capacity.cmd` | `production-capacity-fixture`，`<package>/user-data/production-capacity/`；五格生产容量样例 |
| 可选真实命令 | 用户的外部本机配置，`--execution-purpose=manual`，独立的新 `<manual-data>`；不把真实配置或账本放入包 |

同一时刻只运行一个游戏实例。重新启动进入该模式的新世界；需要续接时按 F9 读取其最近存档。重新解压候选应使用新目录，保留前一候选的数据与反馈；不要把旧候选存档复制来充当本候选的新验收结果。

每行的 `F(ID)` 是反馈定位号，可直接在聊天中报 ID、入口、操作和现象；`<data>/manual-feedback.md` 与 `<data>/manual-feedback/<ID>-<序号>.png` 是可选留档位置。有画面问题时再补系统缩放、实际窗口尺寸及截图；涉及资产或恢复时补日期时间、钱包、相关物品与完整提示。能操作时从菜单或观察手册“导出观察记录”，反馈此次 `<data>/exports/<时间>-<后缀>.zip` 的文件名；无需人工阅读 JSONL。退出前保留整个 `<data>`：`save.json`、`save.json.previous`（如有）、`runs/<branch>/events.jsonl`、`exports/` 和反馈图片，不单独删父分支。若界面无法导出，直接保留目录和包内启动日志，注明卡住位置。

每项填写“通过 / 失败 / 未测”，不把未测留空。无截图的口头通过仍记录实际覆盖项；旧生产票与旧对话票的人工通过只作历史链接。

## 键位与界面边界

- WASD / 方向键支持持续移动。点击可走地面创建路线，方向键输入取消点击路线。当前鼠标只在左键按下时取一次目标；按住并拖动鼠标没有持续追随的契约。
- 靠近目标按 E，或点击底部交互按钮。附近店铺、地块、床、生产目标会优先于居民；想与邻居交谈可用独立“和邻居聊聊”按钮。
- B 为只读背包；1～5 / 点击快捷格选择，不使用或消耗物品。数量输入框有焦点时数字应输入数量，不切快捷格。
- F5 保存、F9 读取。Tab / “观察手册”打开观察；点击居民或顶部头像跟随该居民，“回到玩家”返回。观察手册本身不暂停世界。
- Esc 在商店/菜园/睡眠/生产中先关闭该面板；在对话中打开叠加菜单。对话用“继续散步”关闭。菜单、失焦与各生活面板分别持有暂停，全部解除后才恢复。
- 可见地点：橡木杂货店门口、菜园六块地、菜园下方鸡舍、河岸池塘、暖炉小馆厨房、“我的家”门口。先走近，确认底部 E 标签再打开，避免隔着建筑或河水交互。

## 可选真实试玩：只由用户执行

使用包装说明中的外部配置模板，绑定已经存在的 `full-demo-v2` 账本。示意命令：

```powershell
& '<package>/CozyTown.exe' -- --model-config='<absolute-local-config.json>' --execution-purpose=manual --data-dir='<new-absolute-manual-data>'
```

无需安装 SDK；包内没有真实启动脚本。共享 `manual` 阶段最多 8 次，含 NPC 自主调用、玩家文本、失败和恢复补发；不是额外八次玩家文本，也不按读档返还。只启动一个实例，达到上限保留固定回应/规则回退，不初始化账本、不扩额、不补样。正常走动时 NPC 已可能使用该额度，因此可优先靠近目标后打开对话；不承诺剩余次数必能覆盖四个玩家生成。
