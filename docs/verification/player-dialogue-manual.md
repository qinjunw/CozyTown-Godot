复测时使用同一候选导出包，在 PowerShell 7 中运行以下入口；`Executable` 指向包内的 `CozyTown.exe`，保留它旁边的导出数据文件。

```powershell
pwsh -File tools/windows/run-dialogue-fixture.ps1 -Executable '<absolute-path-to-CozyTown.exe>' -Fixture success
```

脚本打开可见游戏窗口，仅传入离线样例与数据目录。每次运行在 `artifacts/dialogue-manual/<fixture>-<UTC时间>-<随机后缀>` 创建独立目录，并输出目录及进程编号。可用 `-DataRoot <absolute-directory>` 改变根目录；保存、运行记录和导出均留在这次运行的目录中。

| `Fixture` | 操作与预期 |
| --- | --- |
| `success` | 分别靠近 Mina、Eli、Ren、Sora，按 E 打开。姓名、肖像和固定回应对应居民，世界时钟暂停。点击生成后显示该居民的一段固定客户端示例与来源，生成按钮禁用；继续散步恢复世界。 |
| `delayed` | 生成后等待约两秒出现回复。生成后立即按 Esc 打开菜单，或切出应用：叠加暂停期间新文本不出现，解除后才展示。另开一次会话，生成后立即关闭或点击顶部另一位附近居民的头像；旧回复不能替换新面板，新会话不自动生成。 |
| `invalid` | 点击生成后显示格式原因与固定回退，仍可关闭对话，不能在本会话再次生成。 |
| `timeout` | 点击生成后显示等待余量，满 60 秒显示超时原因与固定回退。菜单或失焦期间 60 秒逻辑等待余量仍递减；解除前不展示新回退文本。 |
| `budget` | 点击生成后显示共用实验额度不可用与固定回退，仍可关闭对话，不能在本会话再次生成。 |

在 `timeout` 中生成后立即按 F5，数秒后按 F9：面板恢复原居民与保存时的等待余量。关闭该会话后，再按 F9 读取旧等待档：固定回应仍在，状态说明这次生成已在先前分支终结，按钮不能再次生成。玩家只需确认居民、固定回应、终结说明和按钮状态。存档固定回应的经历资格、一次提交与无未来文本导入，由代理的公开 Host 和回放检查验证，无需人工检查日志字段。

在 `delayed` 中分别保存等待状态和回复已显示状态再读取。等待状态续接原会话；已显示状态保留原文本。菜单打开时读档，解除菜单前不得派发或展示新文本。经历去重由代理自动结构检查，无需人工查日志。
