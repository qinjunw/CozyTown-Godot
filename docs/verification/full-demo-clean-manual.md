## 准备与反馈

将整个 ZIP 解压到可写的新目录，双击 `Start.cmd`。无需安装 .NET；默认居民使用规则，对话生成使用固定客户端，不发送 HTTP。`Start-1920.cmd` 共用普通档，其他入口各有独立数据目录。同一时刻只开一个实例；重启是新世界，按 F9 才读取最近存档。

每组反馈“通过 / 失败 / 未测”，可直接在聊天中报组号、入口、操作和现象；也可留在 `<package>/user-data/<mode>/manual-feedback.md`。有画面问题再附窗口尺寸、Windows 缩放及截图。可操作时从菜单或观察手册导出记录，记下 ZIP 文件名；保留整个数据目录，不必人工阅读 JSON。详细材料、键位、每一步预期及故障入口见[步骤附录](full-demo-clean-manual-details.md)。

| 1. 启动、移动与交易 | 新档；WASD/方向键持续移动、撞墙和河岸；点击地面后按方向改道，点击 UI。到杂货店买胡萝卜种子 1、番茄种子 1、饲料 2、面粉 1；尝试一次超额交易，B 看背包、1～5 选快捷格。（B01～B02） | 资源与文字齐全，碰撞有效，UI 不穿透成移动；买卖数量和钱包一致，失败不扣资产，快捷选择不消耗。鼠标仅按下时取一次路线目标，长按拖动不持续跟随。 |

## 数据与可选真实模式

普通档为 `user-data/baseline/`，对照为 `user-data/counterfactual/`，异常对话为 `user-data/dialogue-<fixture>/`，容量为 `user-data/farming-capacity/` 与 `user-data/production-capacity/`。启动日志位于对应目录，存档为 `save.json`，观察导出为 `exports/`。完整运行分支在 `runs/`，反馈时保留父分支。

可选真实试玩只由用户显式执行。将包内 `config/full-demo.example.json` 复制到包外本机目录，填写外部凭据路径及**现存共享 v2 账本**路径，不新建账本；不把配置或账本发回仓库。以下命令无需 SDK：

```powershell
& '<package>/CozyTown.exe' -- --model-config='<absolute-local-config.json>' --execution-purpose=manual --data-dir='<new-absolute-manual-data>'
```

`manual` 最多 8 次，NPC 自主决定、玩家文本、失败与恢复补发共用；走动时 NPC 已可能消耗次数。读取不返还额度，不补样或扩额。此项可填未测；本包没有真实启动脚本，代理不执行该命令。选择真实模式时按 M01 核对总分母 96、人工已用 / 8、共用说明、预留、保守扣减与停止原因；普通离线入口不显示真实预算，不能据此代填该项通过。
