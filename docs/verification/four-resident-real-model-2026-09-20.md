# 四人场景真实模型实测

本记录执行[预登记计划](four-resident-run-plan.md)，对应[用垂直切片验证 Godot 场景、像素交互与调试体验](https://github.com/qinjunw/CozyTown-Godot/issues/7)。固定输入为提交 `41dc79d13dd72604c4e695b25d20789cfe26c0e4` 的 Windows 导出包，协议 `town-choice-v1`，DeepSeek `deepseek-flash`，关闭思考。两组均以 headless 方式运行同一个 Godot 世界；窗口操作和用户画面反馈另行验收。

## 执行与结果

基准与资源对照各运行一次，使用不同的新数据目录，共用原有持久预算账本。每组在达到 22 次发送后停止新增请求并收完在途响应，未重跑。普通世界时速为每现实秒 0.5 世界分钟；本轮均先达到发送上限，没有运行到 180 秒上限。

| 指标 | 基准 | 资源对照 |
| --- | ---: | ---: |
| 运行秒数 | 53.985 | 46.126 |
| 发送 / 完成 | 22 / 22 | 22 / 22 |
| 世界实际采用的模型候选 | 21 | 20 |
| 米娜 / 艾里 / 阿仁 / 小空的采用数 | 5 / 2 / 9 / 5 | 2 / 5 / 8 / 5 |
| 资源交付 | 2 | 1 |
| 规则回退 | 1 | 1 |
| 本组保守费用（CNY） | 0.144706 | 0.153500 |

每名居民在两组中均至少有一条实际执行的模型候选。服务完成数与世界采用数分别统计；规则回退不计入模型采用。

基准中米娜向阿仁交付 3 份浆果、总价 0；阿仁向小空交付 2 份鱼、总价 4。资源对照中小空向阿仁交付 2 份鱼、总价 0。逐条重算交付后的各人资产与结束快照一致，无重复交付。两组初末总量均为 48 金币、5 浆果、6 鱼、5 谷物、4 汤。

两组仅初始库存分配不同，居民人格、日程、规则、模型协议与代码相同。结果表明这两次运行产生了不同的选择及交付方向；模型及响应到达时序存在非确定性，不能仅凭一对样本将差异全部归因于库存。

## 拒绝与回退

基准中，小空的一条候选因 `participant_busy` 被拒绝并触发规则回退。`resident_ended` 是成功结束会面时关联请求的退休记录，不能重复算作一次服务失败。

资源对照中，艾里收到邀请后旧请求以 `invitation_received` 退休，迟到回复以 `terminal_request` 隔离；另一条候选含动作不允许的字段，以 `unexpected_action_fields` 拒绝并触发规则回退。`conversation_complete` 对应会话完成后的关联请求退休。全部记录均留在分母与原始 JSONL 中，未删去未采用样本。

## 预算与证据

两组增加 44 次发送，承接接口探针的 4 次后达到 **48 / 48 次总上限**。保守累计结算为 CNY **0.300418**，预留费用 0、占用槽位 0、未结算尝试 0、恢复补发 0。剩余金额 CNY 4.699582，但发送额度已经用尽。费用按登记的输入全未命中峰值费率记账，不是服务商实际账单。

[可核对统计](evidence/four-resident-slice/real-model-analysis.json)记录来源版本、初态、输入及内容摘要、每人实际选择、拒绝原因、全部尝试和费用、守恒检查及原始文件 SHA-256。完整本地记录位于 `artifacts/real-experiments/20260920-41dc79d/`，包含两组 JSONL、初态、结束快照、预算快照、请求结果和启动记录。运行不记录密钥或账户余额。

本轮证明四人真实选择可通过同场世界校验并产生交付，不证明长期稳定性或公开演示画面已经获得用户认可。后续表现修复不改写本轮源码版本或补跑模型样本。
