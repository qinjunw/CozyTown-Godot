# NPC 动作字段与交易约束离线修复

本记录对应[明确模型动作字段与交易资产约束](https://github.com/qinjunw/CozyTown-Godot/issues/37)。2026-10-11 的[旧候选真实评测](full-demo-real-2026-10-11.md)保留全部失败；资源对照组 NPC 合法采用率为 25/36，未达 80%。本次修改仅完成离线修复，不改写旧结果，不证明真实模型采用率提高。

## 修改

新的 NPC 决策输入随 `allowedActions` 提供 `actionConstraints`，逐动作列出必须为 `null` 与 `0` 的字段。`tradeConstraints` 只列该居民自己的可售库存，单次最大数量同时受库存与动作上限 1000 约束；明确报价人出售自己的物品、买方支付总币价、当前协议不支持以物易物。待回复报价列出已有卖方、买方、数量、总价及自己的付款能力；对话阶段保留的旧报价明确标记为历史。

HTTP 系统指令解释这些对象及 `respond` 只能接受或拒绝现有报价。模型仍自行选择允许的动作与对象，可等待、拒绝、发言或结束。执行层的动作字段、数量、资产、目标与承诺校验保持原样，不填补或改写模型候选。

NPC 输入与 HTTP 请求复用一处紧凑 JSON 写入：在序列化后识别真实 Unicode 转义，将可合法直写的字元及有效代理对保留为原字元，成对消费既有转义以保留字面反斜线文本；控制字符、引号和反斜线的必要转义仍保留。该编码只用于这两个 JSON 边界，没有改变全局存档、运行记录或玩家对话编码。保存恢复测试保持旧冻结待办的输入与 HTTP body 字符串原样，因此实际发送的 UTF-8 body 字节不变，恢复不会用新提示词替换已冻结请求。存档 schema、规则版本与数值版本未变。

新输入生成与模拟源代码指纹已经改变；旧冻结待办保留测试不证明新程序能完整回放 `99dbe5e` 的旧真实记录。旧真实证据仍归属旧候选，应使用其归档匹配版本复验，本票不重新执行旧真实包。

公开边界测试覆盖七种动作的字段合同、自有库存、买卖双方、总价、付款能力、历史报价、旧冻结输入/HTTP body 保存恢复，以及带父前缀的回放。输入合同按已确定的字段字面值断言，没有使用提示词措辞测试。
