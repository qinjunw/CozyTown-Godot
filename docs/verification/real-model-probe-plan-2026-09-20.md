# DeepSeek 接通探针计划

目的：验证官方接口、凭据、参数、JSON 候选和用量字段；不声称验证 Godot 身体、四人同场或居民自主互动。

2026-09-20 用户已确认服务路线、CNY 5 / 48 次首轮总预算、本票最多 4 次，并提供仓库外凭据位置。凭据存在、唯一匹配条目、密钥非空已检查通过。预算身份固定为 `cozytown-godot-first-slice-20260920-v1`，总预算跨后续基准/对照阶段延续。

候选请求：DeepSeek Chat Completions，`deepseek-flash`，`thinking.type=disabled`，`response_format.type=json_object`，`stream=false`，`max_tokens=512`。完整输入不超过 16 KiB。只有 Authorization 头包含测试密钥，且仅发送到固定官方 HTTPS 地址，禁止转发重定向。

本轮预期返回型号登记为官方示例中的 `deepseek-flash`；其他返回名触发停止核验，不据此断言提供方协议错误。系统指纹以第一份响应为本轮观察值，后续变化停止派发；指纹缺失不能证明远端版本稳定。

样本使用四份人工编写的小镇上下文，分别以 Mina、Eli、Ren、Sora 为主体。每份仅含自方合成状态、可见人物和至少两个合法行动选择；不使用用户的私人聊天或未公开数据。允许模型等待、接近或邀请可见人物，不指定必须选中的伙伴。输出检查 `operation`、对应目标、短台词与简短依据，不执行任何游戏操作。

本票最多四次顺序发送、不重试；首次鉴权、模型不匹配、结构异常或传输故障时停止并保留证据。调用和费用从同一首轮预算扣除，余量用于后续场景验收；本计划本身不创建或扩充预算。

每次发送前记录配置、输入、尝试身份、预算预留与开始状态。完整响应记录提供方身份、返回模型、系统指纹、finish reason、usage、耗时和候选；错误记录其分类和来源。密钥、授权头、思考字段均不进入输出。按峰时价计算预算扣减，账户实际扣款另行核对。未知用量保留预留；无法确认远端结束的尝试同时保留在途占用。

执行前核验账户币种与研究价目一致，使用同一预算的持久占额，并保存原始输入和非秘密结果。探针通过自检和源代码审查后才运行；本计划登记时尚未发送任何真实请求。
