# 完整 Demo 宿主与离线验证

[宿主阶段与离线评测入口](https://github.com/qinjunw/CozyTown-Godot/issues/35)在代码候选 `71be140d24ade8e78d96ab68113221dfa760e08e` 上通过完整离线门。该候选包含[父分支宿主与预算连续性修复](https://github.com/qinjunw/CozyTown-Godot/issues/36)。本报告与[结果及哈希清单](evidence/full-demo-host/results.json)是随后提交的证据文档，未改变已验证程序。

## 实现与边界

宿主读取凭据路径、账本路径、提供方指纹和预算配置版本，绑定世界预算身份及 `legacy`、`experiment`、`manual` 用途。完整实验的 NPC 新请求按初态路由到 `baseline` 或 `counterfactual`，玩家请求使用 `player_dialogue`；最终试玩的新请求使用保留的 `manual`。恢复沿用冻结请求原阶段。旧配置保留原预算及玩家真实生成保护；配置、用途、预算身份不匹配的保存恢复在发布新世界前拒绝。

[注册输入](../../game/Content/full-demo-input.json)从正常业务入口执行购买、种植浇水、喂鸡、两个日间窗口、两次 12 小时睡眠、领蛋、保存读取和四人对话。行走接受正常耗时并查询 Godot 碰撞；驱动未直接填充资产或移动坐标。`fixed` 每步输入 0.05 秒，CPU 执行时间不计入世界；`real` 使用单调时钟并计入等待与 I/O。窗口保留 180 秒、18 次普通准入和 60 秒共享收尾限制，保存读取不回退驱动游标与窗口计数。预算、鉴权、账本或日志停止阻止后续新增请求，未完成必需操作则失败退出。

运行命令与配置用途见[完整 Demo 运行说明](../FULL_DEMO_RUN.md)。本票没有读取用户凭据或实际账本、初始化本轮真实账本、发送提供方 HTTP 或执行图形验收。

## 失败保留与制品位置

开发过程中保留了购买数量未提交、历史汇总重复及窗口停止测试的原始记录。购买与睡眠改用和面板共同的显式数量业务入口；汇总按事件身份去重；金额、总量和阶段拒绝停止窗口新增准入。PowerShell 会话谓词的换行错误在完整门前修复。

`509230c` 的首次完整门停于六项合并测试：完整预算世界的保存 fixture 仍使用旧预算缺省值。fixture 显式绑定预算配置及用途后，12 项父分支导出测试通过，随后冻结为本报告候选重跑。另一次 `ExpectedCommit` 参数误填被守卫拒绝，没有运行子进程。两份失败报告、红绿 TRX 和日志均保留，未覆盖为通过。

开发故障探针故意占用一个 ZIP 目标：程序以 1 退出，写出失败报告、一个 `IOException` 导出失败及另一份可封存分支。失败出口独立读取安全预算快照，记录 `budgetReadFailure`，逐分支尝试封存并在 `finally` 退出；该固定探针没有触发预算读取故障，也不冒充冻结候选的账本故障实测。
