# 玩家对话操作与状态

靠近居民后按 E，或点击交谈按钮，打开固定回应。面板内的“生成一段反馈”由玩家显式触发，一次会话最多生成一段；四位居民均使用同一入口。普通规则模式使用固定客户端，按钮标注“固定示例”，不联网。当前首切片真实预算配置没有玩家对话阶段，选择生成会显示“当前实验未启用玩家对话额度”并保留固定回应；完整 Demo 的阶段接线由[综合评测合同](FULL_DEMO_EVALUATION_CONTRACT.md)承接。

打开对话会暂停世界与 NPC。仅对话面板暂停时，当前玩家请求可派发和显示；Esc 打开叠加菜单，或应用失焦后，新派发和新文本展示暂停。已经开始的传输仍可封存完整结果。菜单关闭或重新聚焦后继续当前会话。点击“继续散步”关闭对话；对话内点击顶部另一位附近居民的头像会终结旧会话并打开新会话，新会话需要再次点击生成。

F5 保存面板目标、会话、冻结输入、等待余量、封存结果、已显示文本与待提交经历；F9 恢复这些状态。已封存结果直接续接，已显示文本保留原显示阶段。未完成真实请求的恢复补发仍须通过同一持久预算与物理槽；排队也计入 60 秒现实逻辑额度，每次传输最多 30 秒。应用关闭期间不扣除存档中的相对余量。

关闭尚未显示的模型请求后，迟到结果只能记录在原尝试中，不能进入新面板或产生经历。已显示文本的经历在全部暂停解除后的正常世界提交边界写入一次。文本不执行买卖、生产或资产命令。

宿主使用 `player-dialogue-retirements.json` 保存按预算身份和逻辑请求身份索引的终结事实。真实模式将文件放在预算账本所在目录；固定模式放在同一数据目录。该文件与运行分支独立，跨进程阻止通过旧等待存档复活已关闭或已显示的模型请求。恢复仍显示存档中的固定回应，保存时已有的显示经历保留一次提交资格；保存之后的模型文本与经历不导入。终结记录不保存文本或费用，也不释放预算和物理槽。文件缺失、损坏或写入失败时停止相关操作；不使用旧备份自动回退终结事实。

## 固定客户端故障样例

以下参数用于离线验收，不接受模型配置。每次用独立数据目录运行，避免覆盖玩家存档：

```powershell
CozyTown.exe --dialogue-fixture=delayed --data-dir=<absolute-test-directory>
```

| `--dialogue-fixture` | 生成后的行为 |
| --- | --- |
| `success`（默认） | 返回居民各自的一段固定客户端示例 |
| `delayed` | 两秒后封存固定回复，可检查等待、叠加暂停与迟到隔离 |
| `invalid` | 返回不含合法文本的结构，显示格式原因和固定回应 |
| `timeout` | 不返回结果，60 秒逻辑等待到期后显示固定回退 |
| `budget` | 模拟共用发送额度拒绝，显示额度原因和固定回应 |
| `fingerprint-changed` | 固定回复旁显示带“固定样例”标识的指纹变化提示，不发送模型请求 |
| `stopped-fingerprint` | 按服务版本停用显示原因并禁用生成按钮，不创建逻辑请求 |
| `stage-limit` | 按阶段发送次数用尽显示原因并禁用生成按钮 |
| `account-unavailable` | 按账户不可用显示原因并禁用生成按钮 |

真实模式在创建玩家请求前核对共享账本和已知停用原因。服务版本、认证/账户、阶段次数、总次数、金额预留、物理槽与账本故障分别显示；不会把服务版本停用显示成额度不足。两个物理槽或在途金额预留占满时暂缓新生成，结算后可再次操作；未知生成仍占槽时明确提示需要核验，重启或读档不释放占用。已经在途的回复仍按原会话与暂停规则完成。已停止的账本不会因重启、读档或切换为人工用途而解锁。

## 公开接口与记录

`TownWorld` 提供附近交互、显式请求、派发确认、完整到达、结果封存、展示、关闭与外部终结事实应用入口。`TownDialogueHost` 是 Godot 面板与离线验证共用的宿主入口，检查暂停原因、解析单字段 `text` 协议，并在关闭或展示前持久发布终结输入与终结事实。

玩家传输身份使用 `kind=player_text` 与独立 `playerSessionId`；居民自主行为使用 `kind=npc_action`。两类逻辑请求保存在同一 `ModelQueue`，NPC 轮转游标保持独立，玩家会话不覆盖居民自主待办。冻结上下文包含该居民自身状态、合法局部观察、最近相关经历和日程。模型协议只接受一个非空 `text` 字符串，最长 160 字符，拒绝额外字段、重复字段与控制字符。

世界事件分别记录会话打开、请求输入、派发、完整到达、封存响应、文本校验、展示、关闭、外部终结与经历提交，并携带会话和原逻辑身份。世界快照 schema 为 5，规则版本为 `town-social-player-dialogue-v5`；旧 schema 拒读并保护当前世界。

自动化范围和待用户执行的 Windows 清单见[玩家对话验证记录](verification/player-dialogue.md)。
