# 首切片真实模型接入合同

本文件对应[确定首切片真实模型的接入、预算与失败验收](https://github.com/qinjunw/CozyTown-Godot/issues/11)。2026-09-20 用户确认 DeepSeek 与独立 C# 接入、人民币 5 元及 48 次发送的首轮总上限，并提供仓库外凭据文件位置。本合同不声明 Godot 模型适配器或四人场景已经实现；官方依据见[DeepSeek 接入研究](research/deepseek-provider-2026-09-20.md)。

已执行的 4 次接口调用、离线检查及预算余量见[探针实测记录](verification/real-model-probe-2026-09-20.md)。后续场景承接其中的预算消耗；接口通过不替代下文的场景验收。

## 接入路线与配置

采用 DeepSeek 官方 Chat Completions：`https://api.deepseek.com/chat/completions`，请求模型 `deepseek-flash`，显式设置 `thinking.type=disabled`、`stream=false`、`response_format.type=json_object`、`max_tokens=512`。新 Godot 项目通过 C# HTTP 适配器直接调用；独立核心仅处理请求/结果数据和世界规则。普通测试使用固定替身，真实调用显式启用。旧 Unity 的 Python 代理仅作协议与记录参考，不作为运行依赖。

官方当前将 `deepseek-flash` 列为 V4.1 Flash；旧 `deepseek-v4-flash` 已不锁定旧版本。运行清单分别记录请求型号、返回型号、`system_fingerprint`、提供方版本说明、参数和提示词指纹，不能把别名当成可重现的永久版本。检测到提供方版本变化或返回型号不在本次登记范围时停止新派发，保留已发生调用；现有接口不能保证检测所有静默升级。

凭据从用户指定的仓库外 JSON 读取：顶层对象中严格唯一的 `Todo=CozyTown` 条目提供非空 `testingAPIKey`。实际文件路径保存在忽略的本机配置中，文档与样例使用 `<private-credentials.json>`。只向上述固定 HTTPS 服务发送认证，拒绝自动重定向；密钥不进游戏内容、存档、运行记录或导出包。余额查询只用于核验可用状态和账户币种，不把余额写入共享证据。

首版只提供这一条真实服务路径；不用 OpenAI 格式兼容性推定取消、幂等或费用查询能力。玩家交谈若触发模型，也通过同一实验预算和可观察结果通道，不另开未记账调用。

## 请求与候选

宿主信封包含协议版本、实验预算、运行分支、会话代数、逻辑请求与尝试身份、居民、活动修订、观察时刻、有效世界窗口和输入指纹。传输身份由宿主绑定，模型输出不能自行改变归属。

模型只接收该居民的自身状态、冻结的局部观察、相关经历及来源、日程约束、可用操作与合法目标。伙伴未公开的资产、动机和经历不进入上下文；未知信息显式保持未知。至少允许等待或拒绝，正常运行不预先指派唯一社交对象和接受结果。

每次响应提出一个行动候选，如等待、接近、邀请、回应、发言、提出交换或结束。操作所需目标、地点、承诺、交换条件和可选台词必须符合对应类型与本次候选范围；简短依据只作可读记录。无脚本、任意工具执行或直接修改资产接口。台词描述交付不会创建交付事实。

JSON object 模式只约束输出格式，宿主仍检查必填字段、类型、枚举、长度、目标身份、有效窗口和当前条件。截断、空内容、未知操作及非法结构明确拒绝，不从原上下文猜填。首版不自动再次调用模型纠正格式，不使用 SDK 或 HTTP 隐式重试。

全局世界修订是追踪依据，不能因其他居民移动而拒绝全部慢响应。候选受理重新检查自身请求/活动有效性、世界日程和该操作涉及的目标、资产、空间与承诺条件。相关条件改变则拒绝；无关世界变化不自动失效。

## 调度、预算与恢复

首轮参数：每居民最多一个未终结决定，四人轮转；同预算物理并发 2；每次传输最多 30 秒，逻辑等待额度 60 秒且包含排队；输出 512 token；完整请求体最多 16 KiB，超限明确拒绝，不静默截断必要规则或身份。居民新机会由相关状态变化触发，同一居民的普通新派发至少间隔 30 秒现实时间；对已有会话的轮次回应和保存恢复待办仍受队列、窗口及总预算限制。下一次真实决策不得覆盖尚未终结的决定。

四人持续符合派发条件时，在任一居民取得下一轮新派发之前，其余已排队居民应先取得本轮机会。保存队列和轮转游标，恢复补发也排队；居民失去日程窗口时记录跳过原因，不绕过世界日程来凑齐次数。

已批准首轮总预算 CNY 5、最多 48 次发送；固定阶段上限为本票探针 4 次、首切片基准场景 22 次、对照场景 22 次。总预算身份为 `cozytown-godot-first-slice-20260920-v1`，阶段与所有分支共用账本；失败、补发和中断尝试计入原阶段。各阶段限额与总调用量、费用和槽位在同一准入事务核对，不能用新分支或新输出目录刷新次数。真实调用不会自动扩额或重复实验。

金额预留使用官方峰时、全输入未命中价格和完整上下文容量上界，不能凭字数近似把小额估算当成已证明的费用上限。按输入 1,048,576 token、输出 512 token、输入每百万 CNY 2、输出每百万 CNY 8，单次上界为 CNY 2.101248，向上取 CNY 2.11。两并发最多预留 CNY 4.22，完整用量返回后结算并释放未用部分。该计算依赖已登记的官方规格和价格，属于应用内预算，不是提供方账户的硬封顶功能；不包含同账户其他程序的消费。账户币种、模型或价格与登记不符时暂停核验，不能自行换汇套价。

发送前在持久账本中原子占用发送名额、费用和在途槽：已按报告用量结算的预算扣减 + 所有未结算预留 + 本次预留不得超过预算。未结算预留包括正常在途、恢复补发、已有终态但缺 usage、取消/断连及进程退出后状态未知的尝试。结算针对原尝试原子替换预留，不能重复扣减或释放。正常重试为零；读档恢复补发仍按[续接合同](SAVE_REPLAY_CONTRACT.md)在同预算/原逻辑请求跨分支最多一次，并与普通请求共用总量。账本或记录写入失败则不发送。保守占额可能在实际消费尚低于总额度时停止新调用，不能为用满额度自动释放未知项。

费用和在途槽分开结算。与尝试对应的完整提供方生成终态，或提供方明确保证未执行/已结束的证据，可释放物理槽；用量缺失仍保留费用。完整网关错误响应、取消、超时、断连或进程退出只证明本地 I/O 结束，不能据此推定远端停止或免费。未知在途占槽保留，两个槽均未知时停止派发并显示待核验，居民采用合法规则回退。不能靠 TTL、重启或读档释放未知占用；只有与该尝试关联的可靠终态证据才能结清。

目前未核实 DeepSeek 的请求状态查询、断连停止计费或幂等补发保证，因此未知项无法凭本地超时自动解除。恢复补发以全部准入条件满足为前提，槽位不足时等待，逻辑余量耗尽则记录原因并合法回退；不能为兑现自动续接而释放旧槽位。

首轮按完整 `usage` 的全部输入未命中峰时价和输出峰时价计算预算扣减，即每个输入 token 扣 2 微元、每个输出 token 扣 8 微元；即使命中缓存也不预支折扣。报告同时保留提供方缓存分项，区分此保守扣减与账户实际扣款。完整响应已经到达但 `usage` 缺失、结构错误或超出登记上界时，保留证据并停止新派发；尚无完整响应的在途或未知尝试仍按费用与槽位准入规则处理，不把 unknown 写为零。

## 错误与证据

结果分别记录传输完成、解析结果、世界受理/拒绝、行动执行及规则回退。鉴权失败、提供方余额/额度不足、限流、服务器故障、本地预算耗尽、非法候选、过期/重复结果和用量未知须可区分。401/403 或账户不足停止新真实派发；其他故障也不能隐式重试。

记录完整模型输入、候选正文、提供方请求身份、返回型号、finish reason、usage、完整到达时刻、受理边界和配置指纹；不保存密钥、授权头或不需要的模型思考内容。自动化证据与导出记录保留全部失败、中断和回退。

## 首切片验收

接口探针只证明凭据、请求参数与结构化候选可用，不证明人物身体、自主互动或四人共处一个世界。首切片还须用同一 Windows 包完成基准和对照两个初态的四人运行；每组最多 22 次发送，探针与场景共同受 48 次及金额预算约束，不能为补足成功样本无限重跑。

每组四人均须有真实、可解析、参与实际选择的模型决定；最低覆盖合计八份决定，失败与回退不能补数。展示有意义的对象/行动选择和相应世界判定。可以合法拒绝或等待，不能要求固定配对，也不能用脚本补出的会面计入真实成功；没有覆盖的会面/交付阶段单独列出。

对照至少改变资源分布、观察对象或空闲窗口，核验规则输入与机会确实变化，记录模型选择是否变化。所有样本进入分母；两组运行属于覆盖验证，不据此宣称长期成功率。

固定替身验证轮转公平、并发上限、格式/身份/动作错误、条件变化、日程截止、重复与晚到结果、暂停及时回复、两进程竞争恢复名额、崩溃后未知占用、缺账本/写入失败及费用不回退。真实调用不用于故意烧预算测试这些故障。

实际四人场景、故障验收与用户画面反馈由[垂直切片票据](https://github.com/qinjunw/CozyTown-Godot/issues/7)交付。接口探针不得替代[首切片合同](FIRST_PLAYABLE_SLICE.md)中的这些条件。
