# 种植、晨间结算与睡眠

菜园提供六块独立地块。玩家购买种子后，可在附近种植、浇水和收获，再将产物卖给杂货铺。每次种植消耗一颗种子；收获成功后地块清空，可继续种植。

## 操作与成长条件

| 输入 | 结果 |
| --- | --- |
| 靠近菜园地块按 E / 点击交互按钮 | 打开菜园面板，显示可触及的地块、作物、成长次数及浇水状态 |
| 选择种子、浇水或收获 | 按当前库存、地块状态和背包容量检查并执行 |
| 靠近玩家家门口按 E / 点击休息入口 | 选择 1～12 个整小时，确认后推进世界并显示醒来日期和时间 |
| Esc / 回到小镇 | 收起面板，解除该面板持有的暂停 |
| F5 / F9 | 保存或恢复作物、双方资产、时间、结算游标及操作去重记录 |

| 作物 | 成熟需要的晨间成长次数 | 每次收获 | 种子买价 | 产物卖价 |
| --- | ---: | ---: | ---: | ---: |
| 土豆 | 2 | 2 | 20 | 20 |
| 胡萝卜 | 3 | 2 | 25 | 25 |
| 番茄 | 4 | 3 | 30 | 30 |

每日 05:00，未成熟且已经浇水的作物成长一次；结算后清除浇水状态。再次成长前需要重新浇水。同一天重复浇水不会预存后续天数的水。未浇水的地块显示缺水并停留在原成长阶段，世界时间、其他地块和商店补给继续推进。成熟作物保留到玩家成功收获。

种子不足、地块已占用、作物未成熟、距离过远或背包装不下时，面板显示原因。失败不扣除种子、不创建产物，也不清空成熟作物。背包与交易规则见[玩家资产与商店操作](PLAYER_ECONOMY.md)。

### 普通新档的生活闭环

1. 到橡木杂货铺购买一颗胡萝卜种子。新档第一日有胡萝卜种子，购买后剩余 275 金币。
2. 到菜园选择空地，种植胡萝卜并浇水。
3. 回家休息，跨过下一次 05:00。每次最多休息 12 小时，可连续确认；面板显示每次醒来时间。
4. 每完成一次晨间成长，回到菜园浇水。累计三次成长后收获两根胡萝卜。
5. 到杂货铺出售两根胡萝卜，得到 50 金币。未购买其他物品时余额为 325 金币；可用当日供应的种子开始下一轮种植。

## 时间、居民与模型等待

日期在午夜改变，生产和补给在 05:00 结算。睡眠按选择的小时数推进，与正常推进共用核心时间入口；每次跨越日程切换、会面截止及晨间结算点时分别处理。四名居民沿实际路线移动并执行身体空间查询，保留行程、阻塞、到场及承诺阶段。

菜园或休息面板暂停正常帧推进，但允许对应的明确操作。菜单、失焦、读档和故障等其他暂停原因继续阻止睡眠。睡眠提交不开放模型派发门；模型请求仍在解除暂停后的正常宿主处理阶段准入。

睡眠传入的现实等待增量为零，不将休息的世界小时数当作模型等待秒数。实际经过的宿主时间仍由单调时钟计量；菜单和失焦期间，未收到结果的模型请求继续消耗现实等待额度。世界日程结束可使原待办失效，此时旧响应不能恢复已经结束的活动。

核心单次推进上限为七个世界日。一次请求跨多个结算点时，在候选世界中完成整段推进后统一发布；任一结算失败，保留该请求前的时间、未消费推进量、生产、资产、结算游标、居民和待办。此前已经独立完成的推进请求保留。

## 内容与确定性补给

地块位置和玩家休息入口由 `game/World/TownMap.tscn` 的地点标记维护；`game/Content/town.json` 的 `farming` 定义作物条件、地块引用、床地点与商店补给表。条件和报价采用固定 Unity [默认内容](https://github.com/qinjunw/CozyTown/blob/68a1dde7c7099f3e9ee7e975141d0bf9d18099aa/Assets/CozyTown/Runtime/Content/DefaultMvpContent.cs)作为参考。

商店每日 05:00 用当日确定性结果替换整份库存，保留商店钱包。前日剩余或玩家售出的物品不追加到新库存。生成结果由世界种子 12345、商店身份、日期、算法版本和配置项顺序确定，同日重复读取不重抽；种子、概率、数量范围及最少供应种类数都进入模拟内容指纹。

初态从第一日 09:00 开始，使用第一日库存与对应结算游标；新运行不倒补已经过去的 05:00。修改作物、补给、空间引用或其他模拟内容后，旧档按兼容性检查拒绝读取，不用新初态覆盖旧档内容。

### 满包验证初态

`farming-capacity-fixture` 用于检验满包时保留成熟作物。`game/Content/farming-capacity-fixture.json` 明列 300 金币、五格背包，以及胡萝卜种子 2、土豆 1、鸡饲料 1、盐 1、面粉 1。界面标记该验证初态，只接受离线规则模式，并使用独立的内容指纹与存档阶段。普通新档继续使用 24 格空背包。

```powershell
& '<export-directory>/CozyTown.exe' -- --scenario=farming-capacity-fixture --data-dir='<absolute-test-directory>'
```

使用独立数据目录保存验证运行。种下一颗胡萝卜种子后，剩余物品仍占五格；正常浇水并跨过三次晨间成长后，收获应显示背包装不下，作物保持成熟。到杂货铺出售那颗土豆腾出一格，再返回地块收获。这一路径使用正常农场、交易和存档入口，不改运行中的资产或作物。

## 记录与恢复

种植、浇水、收获及睡眠使用独立操作身份。相同身份与参数再次投递返回原结果，不重复扣种子、收获或睡眠；相同身份换参数拒绝。普通买卖、快捷栏、农场操作、睡眠与晨间结算共享经济输入序号，以便按原顺序核对资产变化。

宿主在发布农场或睡眠候选状态之前，持久写入版本化 `player_farm_command` 或 `player_sleep_command`，记录成功和拒绝请求、结果、完整世界检查点及宿主暂停/路线信息。写入失败保留提交前世界并停止后续推进和派发。

种植消耗、收获产出与商店库存替换有独立来源记录，普通交易仍按双方守恒校验。快照保存每块地的作物身份、成长、浇水、成熟、种植代次与已收获次数，连同晨间游标、晨间回执和操作回执共同校验。已接受但尚未消费的时间也进入快照；恢复前检查必要字段、内容引用和按记录重建的资产及地块状态。

运行包交付输入和检查点。完整核心回放与 Godot 场景回放执行器由后续票交付；存读档或导出成功不代表已经执行记录回放。
