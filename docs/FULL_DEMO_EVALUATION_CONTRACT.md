## 冻结输入和运行安排

两组使用同一源候选、Windows 程序、场景、日程、人格、提示词、生产规则和正常世界时速（每现实秒 0.5 世界分钟）。基准从普通初态开始；对照只用 `Content/counterfactual.json` 改变居民初始资源分布，总资源不变。玩家生产资料通过普通购买取得，不能直接填资产。

每组安排两个相邻日间窗口，各最多 180 秒现实时间。中间从床的正常入口执行两次 12 小时睡眠，跨一次 05:00 晨间结算。固定操作贯穿买饲料与种子、种植浇水、喂鸡、保存恢复、领蛋与再次喂食；作物只增长一天，成熟收获及五种配方由完整固定输入验证门另外覆盖。

每个日间窗口最多新增 18 次普通 NPC 发送，两个窗口最多 36 次，原阶段剩余最多 4 次可供实际需要的恢复。请求来自正常日程、观察和人物规则；不指定互动配对、接受结果或模型动作。窗口达到时长或次数上限即停止新增请求，最多再等待 60 秒处理已有逻辑待办，现实等待及世界推进如实记录。未知槽和未结算金额继续保留，不因切换日间窗口或睡眠清空。

在第二个窗口的预定现实时间点保存并读取；时间点、行走目标、生产命令、对话顺序和停止输入在付费启动前冻结到可执行输入包。是否恰好存在未完成模型请求按实际记录；没有发生恢复补发时不得宣称真实恢复路径通过，固定客户端必须覆盖该路径。

两组分别从正常靠近居民入口，显式为四名居民各生成一段玩家模型对话，共八段计划样本。此阶段暂停世界，使用独立玩家会话和冻结上下文；台词不直接创建生产或交付事实。关闭、切人、菜单/失焦叠加及错误路径使用固定客户端覆盖，真实场景不故意制造付费故障。

离线可行性每组接受了 386.5 秒模拟现实时间，其中两个窗口合计 360 秒、行走 26.5 秒。实际评测还包含 I/O、保存和最多两次 60 秒收尾；四次玩家对话若分别耗尽逻辑额度，另需最多 240 秒。该估计属于计划时长，最终报告记录实际耗时和世界时刻。

## 统计分母与通过标准

每次预算占用、发送前拒绝、实际 HTTP 派发、响应到达、封存、解析、世界判定、执行及回退保留关联身份。以下比例按实际 HTTP 派发尝试计算，不把发送前拒绝当成传输成功；未派发预算占用和所有拒绝另表报告。恢复是独立物理尝试，逻辑采用和经历提交按逻辑请求去重。

| 指标 | 分母与通过标准 |
| --- | --- |
| 传输完成率 | 取得提供方完整生成响应的尝试 / 实际 HTTP 派发尝试，至少 90%；超时、断连、网关错误和 unknown 均不算完成 |
| 结构解析率 | 通过本次协议结构检查的响应 / 完整生成响应，至少 90%；空内容和截断计失败 |
| 世界合法采用率 | 获世界采用的真实逻辑结果 / 有可解析候选的逻辑请求，至少 80%；过期、旧会话和规则拒绝单列 |
| NPC 覆盖 | 两组的两天中，四名居民每天各至少一次被世界采用的真实决定，最低 16 份；合法等待、拒绝或结束可计入 |
| 玩家对话覆盖 | 两组各四名居民均至少一次在正确玩家会话显示真实文本，最低 8 段；固定反馈不能补数 |
| 状态边界 | 重复执行、重复经历、越权修改资源和错误会话展示均为零 |

NPC 与玩家分别报告比例、计数和覆盖，同时给出合计；零分母写为无样本，不写 100%。规则回退数量、来源和占比单列，不算模型成功。世界采用、实际移动/到场、会面和资源交付分别计数；合法拒绝或等待不要求产生合作，两个资源分布下相同选择也按事实记录。小样本只证明本次覆盖，不估计长期可靠率。

## 执行门、停止与修复

1. 先完成生产/经济、四人入口、玩家对话和保存恢复的固定客户端检查，以及同一输入包的核心回放、Godot 场景回放、缺依赖拒绝和首分歧检查。离线门失败不派发真实请求。
2. 冻结源提交、内容与提示词摘要、工具链、预算配置和完整输入，确认本机配置引用新账本后执行基准、对照及玩家对话。凭据保持仓库外，不进入包或证据。
3. 金额、总量、阶段或窗口上限先到即停；鉴权/余额错误、预算或日志完整性故障、未知双槽、模型/价格/币种漂移停止新增真实派发。已有费用及不确定项继续保留，候选按合法规则回退。
4. 所有失败和中断保留在原候选报告。未达到通过标准时保持综合评测票开放，修复并重新核对受影响的离线项；本次授权不包含自动付费重跑或补样。旧付费样本继续归属旧候选，额外真实运行另问用户。
5. 用户最终试玩从剩余 `manual` 阶段获得最多 8 次发送。没有有效余量、发生停止条件或用户选择离线时，使用明确标记的固定客户端与既有真实证据；不能临时扩额。

共享配置模板仅保存预算身份、阶段上限、模型与指纹、场景及逻辑账本位置。真实路径使用 `<private-credentials.json>`、`<full-demo-ledger.json>` 等占位符；实际机器路径留在忽略的本机配置。完整原始记录保留在私人仓库或关联制品，报告附可定位清单、哈希和未知项。
